# Simple Blog with Next.js & Strapi

A modern and simple blog application built with **Next.js** for the frontend and **Strapi** as a Headless CMS for serving and managing content via API.

**Live Demo:**  
[ https://simple-blog-pi-inky.vercel.app/ ]

---

## About The Project

This project is a dynamic blog platform built to seamlessly display articles, categories, and users. All content is fetched dynamically from the **Strapi CMS** admin panel, and the frontend is deployed on **Vercel** to ensure high performance and fast loading speeds.

---

## Key Features

- **Articles:** Dynamic listing and detailed views for blog posts.
- **Categories:** Categorized articles for structured browsing.
- **Users:** Display author and contributor profiles.
- **High Performance:** Fast page loads and responsiveness optimized with Next.js features.
- **Responsive Design:** Fully responsive layout across mobile, tablet, and desktop screens.

---

## Tech Stack

- **Frontend Framework:** [Next.js](https://nextjs.org/) (React)
- **Headless CMS (Backend):** [Strapi](https://strapi.io/)
- **Deployment & Hosting:** [Vercel](https://vercel.com/)
